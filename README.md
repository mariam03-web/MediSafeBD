# MediSafe BD — Final Project Package

The homepage visual design is based directly on the supplied MediSafe BD front-page code. The project keeps the same warning bar, dark header/navigation, AI box, portal cards, service cards, emergency banner, and footer.

## Structure
- `index.html` — Front Page
- `patient-login.html` — Patient two-step login
- `patient-portal.html` — Patient Portal
- `pages/doctor-login.html` — Doctor login
- `pages/doctor-portal.html` — Doctor Portal
- `assets/style.css` — portal/auth styling
- `js/app.js` — demo data and functionality
- `backend/` — separate Express backend starter
