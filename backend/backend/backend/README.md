# MediSafe BD Backend
This is a separate Node.js/Express starter. GitHub Pages can host the static frontend, but it cannot run this Express server.

Run:
1. Install Node.js.
2. Open this backend folder in a terminal.
3. Run `npm install`
4. Run `npm start`
5. Open `http://localhost:3000/api/health`

This is a prototype only. Do not store real medical data here. Production needs a secure database, authentication, authorization, encryption, audit logs, backups, and secure file storage.
